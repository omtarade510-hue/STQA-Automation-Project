# Automated Regular Expression Testing of a Dynamic Web Application Using Selenium WebDriver

## 1. Project Overview

This project demonstrates automated testing of a dynamic web application using Selenium WebDriver and Java. It focuses on testing user registration form fields and validating input data using Regular Expressions (Regex).

The application contains a registration form where users enter their full name, email address, mobile number, date of birth, and password.

## 2. Objectives

- To understand software testing and test automation.
- To automate web application testing using Selenium WebDriver.
- To validate user input using Regular Expressions.
- To identify valid and invalid registration data.
- To understand functional testing of a web application.

## 6. Installation and Execution

### Requirements
- Java JDK
- Eclipse IDE
- Selenium WebDriver Java libraries
- Google Chrome
- XAMPP
- MySQL

### Steps to Run the Website

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the Website folder into the XAMPP `htdocs` directory.
4. Import the database SQL file into phpMyAdmin.
5. Open the browser.
6. Visit:

```text
http://localhost:8080/STQA_Project/
```

### Steps to Run Selenium

1. Open Eclipse IDE.
2. Import or open the Java project.
3. Add Selenium Java libraries to the Java Build Path.
4. Open `STQATest.java`.
5. Run the class as a Java Application.
6. Observe browser automation and test results in the Eclipse Console.
